## ✨ المميزات
- **الرئيسية:** كورسات بصورة ووصف وعدد (فيديوهات/PDF/روابط)، بحث وتصنيفات، وضع ليلي/نهاري، مفضلة، مشاركة وQR Code لكل كورس.
- **صفحة الكورس:** وحدات وفصول، مشغل يوتيوب محمي (طبقة Overlay تمنع الكليك يمين ونسخ الرابط والسحب + علامة مائية + تعطيل الاختصارات + أزرار تشغيل/تقديم وتأخير 10 ثوانٍ/سرعة/ملء الشاشة)، حفظ آخر درس، نسبة إنجاز.
- **المحتوى:** فيديو/PDF/رابط — تعديل، حذف، سحب وإفلات للترتيب، صورة مصغرة، مدة، مجاني/محمي، تنزيل مسموح/ممنوع.
- **الأكواد:** تُنشأ تلقائياً لكل فيديو محمي، إنشاء جماعي حتى 200 كود، كود مخصص، استخدام مرة/متعدد، انتهاء، تفعيل/إيقاف، تعديل/إعادة إنشاء، حالة (فعال/منتهي/غير فعال/مستنفد)، نسخ، تصدير واستيراد CSV، منع التكرار (Unique في قاعدة البيانات)، والتحقق يتم على الخادم قبل إرسال رابط الفيديو أصلاً.
- **المستخدمون:** تسجيل/دخول/خروج/استعادة كلمة مرور فورية، مفضلة، سجل مشاهدة، استكمال المشاهدة، تقدم لكل كورس، علامات إتمام.
- **المطورون والمعلمون:** داخل لوحة المطور يمكن إضافة مطورين ومعلمين وطلاب وتغيير صلاحياتهم؛ وفي الخارج زر **«انضم كمعلم»** يرسل طلباً يوافق عليه المطور فينشأ حساب معلم (كلمة مؤقتة `Teacher2026!`).
- **تخصيص الواجهة (لوحة المطور ← 🎨 تخصيص الواجهة):** تغيير أي نص، رفع الصور، تحريك الأقسام وإخفاؤها، لون المنصة، وإضافة أقسام مخصصة بنص وصورة وزر.
- **لوحة المطور:** إحصائيات (مستخدمون/كورسات/فيديوهات/PDF/روابط/مشاهدات/أكواد نشطة ومنتهية/أكثر الفيديوهات مشاهدة/آخر المستخدمين وتقدمهم)، بحث شامل (كورس/فيديو/PDF/رابط/مستخدم/كود)، سجل عمليات Audit، إشعارات، نسخ احتياطي JSON، معالج «إنشاء كورس جديد» كامل.
- **الأمان:** كلمات مرور مشفرة بـ bcrypt، جلسات HttpOnly موقعة، تحقق من الصلاحيات على الخادم في كل API إدارة، حظر 15 دقيقة بعد 5 محاولات دخول خاطئة، والفيديو المحمي لا يصل رابطه للمتصفح قبل تفعيل كود صحيح.

## 🚀 التشغيل محلياً
```bash
npm install
# أنشئ ملف .env
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
SESSION_SECRET=any-long-random-string
npx drizzle-kit push   # إنشاء الجداول
npm run dev            # http://localhost:3000
```
تُزرع بيانات تجريبية (4 كورسات بأكواد جاهزة) تلقائياً عند أول تشغيل. لعرض أكواد أي فيديو: دخول المطور ← أكواد الفيديوهات.

## ☁️ النشر مجاناً (بدون بطاقة بنكية قدر الإمكان)
| الخدمة | المجاني | الاستخدام |
|---|---|---|
| Vercel Hobby | مجاني | استضافة Next.js |
| Neon أو Supabase | 0.5GB مجاناً | PostgreSQL (`DATABASE_URL`) |
| YouTube (غير مدرج Unlisted) | مجاني بلا حدود | الفيديوهات |
| Google Drive | 15GB مجاناً | ملفات PDF |
| api.qrserver.com | مجاني | QR Codes |
على Vercel: اربط مستودع GitHub ← أضف `DATABASE_URL` و `SESSION_SECRET` في Environment Variables ← Deploy.

## 📱 PWA
الموقع قابل للتثبيت: من متصفح الموبايل اختر «إضافة إلى الشاشة الرئيسية» — ملف `public/manifest.json` و `public/sw.js` جاهزان مع كاش للعمل السريع.

## ⚠️ حدود الخطة المجانية
- حماية يوتيوب تمنع الوصول العادي والنسخ داخل المنصة، لكن لا توجد حماية مطلقة لأي فيديو على الإنترنت — اجعل الفيديوهات «غير مدرجة» دائماً.
- استعادة كلمة المرور فورية داخل الموقع (بدون خدمة بريد مدفوعة)؛ لرسائل بريد حقيقية يمكن ربط Resend/Brevo المجاني لاحقاً.
- تنزيل الفيديوهات غير مفعّل افتراضياً (يوتيوب لا يسمح)، وخيار «التنزيل» في المنصة خاص بملفات PDF على درايف.
